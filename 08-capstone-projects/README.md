# Phase 8: Capstone Projects

End-to-end projects that combine multiple services from earlier phases into a single deployable, documented system. These are what you walk through in interviews.

## Projects

- [ ] [01 - Secure 3-Tier Web App](01-secure-3tier-webapp/README.md) — VPC, ALB, WAF, ASG, RDS, Terraform, CI/CD security gates
- [ ] [02 - Serverless Secure API](02-serverless-secure-api/README.md) — API Gateway, Lambda, DynamoDB, Secrets Manager
- [ ] [03 - EKS Secure Cluster](03-eks-secure-cluster/README.md) — EKS, IRSA, ECR image scanning

## Rule for capstones
Each capstone must include: architecture diagram, IaC source, a documented failure you hit and fixed, and a cost estimate.
